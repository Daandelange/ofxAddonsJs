About ofxAddons

This page is an unofficial browser for the openFrameworks addon ecosystem.
It uses danoli3/ofxAddons, whose periodic crawl produces the addons.json database.

How the list is built

The crawler searches GitHub for repositories that look like openFrameworks addons (by naming convention and by the ofxaddon topic tag), then records their metadata: stars, forks, examples, activity dates, and whether the repo follows the standard addon layout.

Some manual filtering has been done and can be seen in the source code.

Reading the flags

  • s — has a valid addon folder structure (src/, examples, etc. per the community ofxAddonTemplate)
  • mk — ships a Makefile
  • r — has tagged GitHub releases
  • Forks — forks of the addon that are newer than the addon itself, in case a fork is better maintained
  • Branches ahead — branches within the same repo that are ahead of its default branch

URL options

By default every matching addon renders at once. Append ?limit=60 to the page URL (any number works) to switch to batched loading with a "Load more" button instead — useful on slower devices or connections.
